# По порядку — React-чеклист

Готовая контрольная точка по предмету «Разработка веб-приложений (React)».
Стек: **Vite + React + TypeScript + @emotion/react + @emotion/styled**.
Весь исходный код приложения и конфигурация Vite написаны на TypeScript.

## Установка и запуск

Требуется Node.js 22.12+ (либо 20.19+) с npm. Откройте терминал в папке проекта:

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

```bash
npm run typecheck  # проверка TypeScript
npm run build      # проверка типов и сборка в dist/
npm run preview    # локальный просмотр собранного приложения
```

При наличии package-lock.json для воспроизводимой установки можно использовать `npm ci`.

## Возможности

- Добавление задачи кнопкой или Enter; пробелы по краям удаляются.
- Удаление задачи.
- Отметка выполнения чекбоксом с перечёркиванием текста.
- Редактирование: «Изменить», затем «Сохранить» или Enter; «Отмена» или Escape отменяют изменения.
- Пустой текст не принимается; длина ограничена 200 символами.
- Фильтры «Все», «В работе», «Готово», счётчики и прогресс.
- Сохранение в localStorage и восстановление после перезагрузки.
- Адаптивный интерфейс, подписи элементов управления и фокус для клавиатуры.

При первом запуске показаны три примера. Их можно изменить или удалить. Пустой список тоже сохраняется.
Данные хранятся только в текущем браузере для текущего адреса сайта; сервера и синхронизации между устройствами нет.
При запрете записи в localStorage появляется предупреждение, приложение продолжает работать в памяти.

## Структура

```text
src/
  components/
    TaskForm.tsx       — форма добавления
    TaskItem.tsx       — задача и форма редактирования
    TaskList.tsx       — список и пустое состояние
    TaskFilters.tsx    — фильтры
  hooks/useTasks.ts    — состояние, операции и localStorage
  types.ts            — Task и Filter
  styles.ts           — общие Emotion-компоненты и стили
  App.tsx             — сборка экрана и вычисление прогресса
  main.tsx            — точка входа
```

`useState` управляет задачами, фильтром и полями форм. `useEffect` сохраняет изменения.
Массив обновляется неизменяемо через `map`, `filter` и spread. Идентификаторы создаются через `crypto.randomUUID()` (localhost или HTTPS).
Входящие данные localStorage проверяются во время выполнения; TypeScript работает в строгом режиме.
`Global` из Emotion задаёт общие стили, `styled` — стили компонентов, включая состояние выполненного дела.

## Проверка вручную

1. Добавьте задачу, затем попробуйте добавить одни пробелы.
2. Отметьте дело: текст должен перечеркнуться, счётчик и прогресс — обновиться.
3. Измените текст и сохраните Enter. Проверьте отмену через Escape.
4. Переключите все три фильтра, затем удалите задачу.
5. Обновите страницу: список и статусы должны сохраниться.
6. Удалите все задачи и обновите страницу: примеры не должны появиться снова.
7. Проверьте интерфейс в узком окне и навигацию клавишей Tab.

## Загрузка в GitHub

Создайте пустой репозиторий на GitHub, затем в папке проекта выполните:

```bash
git init
git add .
git commit -m "Add React TypeScript checklist"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/react-checklist.git
git push -u origin main
```

Замените `YOUR_USERNAME` и имя репозитория своими. `.gitignore` исключает зависимости, сборку и локальные секреты.
Папку `node_modules` загружать не нужно. `package-lock.json` нужно добавить в репозиторий.
